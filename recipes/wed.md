# \# 水曜日

# 

# \## 🍳 調理の流れ

# 

# ① キャベツを短時間湯通しし、冷凍ブロッコリーをレンジ加熱する

# → ② 鮭ときのこ・玉ねぎを準備する

# → ③ きのこ・玉ねぎに調味料を絡めてホイルに包む

# → ④ フライパンで蒸し焼きにする

# → ⑤ 蒸し焼きの間に味噌汁を作る

# → ⑥ サラダを和える

# → ⑦ 主菜に味を調整して盛り付ける

# 

# \---

# 

# \## 主菜：鮭ときのこのホイル焼き

# 

# \### 材料（1人分）

# 

# \* 鮭：1切れ（約100g）

# \* しめじ：1/2パック

# \* えのき：1/2袋

# \* 玉ねぎ：1/8個

# \* 酒：小さじ1

# \* しょうゆ：小さじ1

# \* みりん：小さじ1

# \* 塩・こしょう：少々

# \* ポン酢またはレモン：適量

# 

# \### 作り方

# 

# 1\. 玉ねぎを薄切りにする。

# 2\. しめじは石づきを取ってほぐし、えのきは石づきを取って食べやすい長さに切る。

# 3\. ボウルに玉ねぎ・しめじ・えのきを入れ、しょうゆ・みりん・酒を加えて軽く混ぜる。

# 4\. アルミホイルを広げ、中央に調味料を絡めた玉ねぎ・きのこを広げる。

# 5\. その上に鮭をのせ、塩・こしょうを少々ふる。

# 6\. アルミホイルの上下を合わせて折り、左右の端もしっかり折り込んで、蒸気が逃げにくいように包む。

# 7\. フライパンに水50～70mlを入れ、ホイル包みを置く。

# 8\. 蓋をして弱火～中弱火で10～12分蒸し焼きにする。

# 9\. フライパンの水が完全になくなりそうなら、20～30ml程度追加する。

# 10\. 鮭の中心まで火が通っていることを確認する。

# 11\. ホイルを開け、味を確認する。必要ならポン酢を少量かける。レモンを添えてもよい。

# 

# \### ポイント

# 

# \* 今回は、\*\*きのこ・玉ねぎに先にしょうゆ・みりん・酒を絡める\*\*ことで、野菜にも味がつくようにします。

# \* 鮭を調味料の上に乗せて蒸すことで、鮭のうま味もきのこ・玉ねぎに回ります。

# \* フライパンに入れる水はホイルの中には入れません。

# \* きのこや玉ねぎからも水分が出るため、ホイルの中に水を入れる必要はありません。

# \* 強火にすると水が早く蒸発するため、弱火～中弱火で加熱します。

# \* ポン酢は最初からたくさんかけず、\*\*食べるときに味を見て少量追加\*\*します。

# 

# \---

# 

# \## 副菜：キャベツとブロッコリーのサラダ

# 

# \### 材料（1人分）

# 

# \* キャベツ：80g

# \* 冷凍ブロッコリー：50g

# \* ポン酢：小さじ1

# \* オリーブ油：小さじ1/2

# \* かつお節：少々（お好みで）

# 

# \### 作り方

# 

# 1\. キャベツをできるだけ細切りにする。

# 2\. 鍋に湯を沸かす。

# 3\. 沸騰した湯にキャベツを入れ、\*\*30～40秒だけ湯通しする\*\*。

# 4\. ザルに上げ、広げて粗熱を取る。水っぽい場合は軽く水気を絞る。

# 5\. 冷凍ブロッコリーを電子レンジで加熱する。

# 6\. ブロッコリーの粗熱を取り、キャベツと合わせる。

# 7\. ポン酢とオリーブ油で和える。

# 8\. お好みでかつお節を加える。

# 

# \### ポイント

# 

# \* レンジで長く加熱する代わりに、\*\*短時間だけ湯通し\*\*します。

# \* 30～40秒程度なら、キャベツのシャキシャキ感を残しやすくなります。

# \* 生のキャベツより青臭さも抑えられます。

# \* 湯通し後は余熱で火が入りすぎないよう、ザルに上げて広げます。

# 

# \---

# 

# \## 汁物：きのこたっぷり味噌汁（1人分）

# 

# \### 材料

# 

# \* だし：200ml

# \* しめじ：1/4パック

# \* えのき：1/4袋

# \* 木綿豆腐：50g

# \* 味噌：小さじ2程度

# 

# \### 作り方

# 

# 1\. きのこを食べやすく切る。

# 2\. だしにきのこと豆腐を入れて煮る。

# 3\. 火を弱めて味噌を溶き入れ、沸騰直前で火を止める。
