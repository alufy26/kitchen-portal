# 月曜日

## 🍳 調理の流れ

① 野菜を切る → ② キャベツを塩もみする → ③ もやしを洗う → ④ 主菜の野菜を蒸し煮にする → ⑤ サバ・ブロッコリー・調味料を加えて蒸し煮にする → ⑥ 水溶き片栗粉でとろみをつける → ⑦ 味噌汁を作る → ⑧ 副菜を仕上げる

---

## 主菜：サバとブロッコリー・もやしの和風あんかけ

### 【材料・1人分】

- サバ水煮缶：1/2～1缶
- 冷凍ブロッコリー：70g
- もやし：1/2袋（約100g）
- 玉ねぎ：1/4個
- にんじん：1/8本程度（薄切りまたはせん切り）
- 水：50ml
- しょうゆ：小さじ1
- 酒：小さじ1
- しょうがチューブ：小さじ1/2
- 片栗粉：小さじ1/2
- 水（片栗粉用）：小さじ1
- ごま油：小さじ1/2（仕上げ用）

### 【作り方】

1. 玉ねぎ1/4個を薄切り、にんじん1/8本を薄切りまたはせん切りにする。
2. もやし1/2袋（約100g）を洗い、水気を切る。
3. フライパンに玉ねぎ・にんじん・もやしを入れ、しょうがチューブ小さじ1/2と水50mlを加える。
4. ふたをして中火で3～4分蒸し煮にする。
   - 水分がほとんどなくなった場合は、水を大さじ1程度追加する。
5. 野菜がしんなりしてきたら、サバ水煮缶1/2～1缶を加える。
   - サバ缶の汁が残っている場合は、一緒に加えてよい。
6. 冷凍ブロッコリー70gを加え、しょうゆ小さじ1・酒小さじ1を全体に回しかける。
7. ふたをして弱めの中火で2～3分蒸し煮にする。
8. 片栗粉小さじ1/2と水小さじ1を混ぜて水溶き片栗粉を作る。
9. 水溶き片栗粉を回し入れ、全体を軽く混ぜながら1分ほど加熱して、とろみをつける。
10. 火を止め、ごま油小さじ1/2を回しかける。

## 副菜：塩もみキャベツとトマトのさっぱり和え

### 【材料・1人分】

- キャベツ：50～60g
- トマト：1/2個
- 塩：ひとつまみ弱
- ポン酢：小さじ1～1.5
- オリーブ油：小さじ1/2

### 【作り方】

1. キャベツ50～60gを細めの千切りにする。
2. キャベツに塩をひとつまみ弱ふり、軽く混ぜる。
3. 5～10分置く。
4. 出てきた水分を手で軽く絞る。
   - 絞りすぎるとシャキシャキ感が弱くなるので、ほどほどでOK。
5. トマト1/2個を食べやすい大きさに切る。
6. キャベツとトマトを合わせ、ポン酢小さじ1～1.5・オリーブ油小さじ1/2で和える。

※キャベツの青臭さが気になる場合は、塩もみ後に水でさっと洗ってから水気をしっかり絞ると、青臭さをさらに抑えられます。

## 汁物：わかめ・豆腐の味噌汁（1人分）

### 【材料・1人分】

- だし：200ml
- 木綿豆腐：50g
- 乾燥わかめ：1g
- 味噌：小さじ2程度

### 【作り方】

1. 木綿豆腐50gを食べやすい大きさに切る。
2. 鍋にだし200mlと豆腐を入れ、中火で温める。
3. 温まってきたら乾燥わかめ1gを加える。
4. 火を弱め、味噌小さじ2程度を溶き入れる。
5. 沸騰直前で火を止める。
