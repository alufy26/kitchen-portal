# 火曜日

## 主菜：鶏むね肉と野菜のにんにく蒸し煮

### 【材料・1人分】

- 鶏むね肉：150g
- キャベツ：100g
- しめじ：1/2パック
- もやし：1/2袋
- 酒：小さじ1
- にんにくチューブ：1～2cm
- 塩：ほんの少々（野菜用）
- 塩・こしょう：少々（鶏肉用）
- ポン酢：小さじ2～2.5
- 水：基本的に不要

### 🍳 調理の流れ

① わかめを水で戻す  
→ ② キャベツ・しめじ・長ねぎを準備する  
→ ③ 豆腐を盛り付け、副菜の準備をする  
→ ④ 鶏むね肉を最後に切る  
→ ⑤ 鍋にキャベツ・もやし・しめじを重ねる  
→ ⑥ 鶏肉と調味料をのせる  
→ ⑦ 弱めの中火から弱火で蒸し煮にする  
→ ⑧ 鶏肉の火の通りを確認する  
→ ⑨ ポン酢を加えて全体に絡める  
→ ⑩ 主菜・副菜を盛り付ける

### 【作り方】

#### ① わかめを戻す

1. 乾燥わかめ1gを水に浸して戻します。
2. 戻ったら水気をしっかり絞り、冷奴用に取り分けておきます。

#### ② 野菜類を下ごしらえする

1. キャベツ100gを食べやすい大きさに切ります。
2. しめじ1/2パックは石づきを取り、手でほぐします。
3. もやし1/2袋は軽く洗い、水気を切ります。
4. 長ねぎは少量を小口切りにして、冷奴用に取り分けます。

※ここまでで野菜類の下ごしらえを済ませます。

#### ③ 副菜の準備をする

1. 木綿豆腐100gを器に盛り付けます。
2. 戻したわかめと長ねぎをのせます。
3. 食べる直前まで冷蔵庫に入れておきます。
4. しょうゆ小さじ1/2は、食べる直前にかけます。

#### ④ 鶏むね肉を切る

1. 鶏むね肉150gを、食べやすい薄めのそぎ切りにします。
2. 鶏肉に塩・こしょうを少々振ります。

※野菜を先に切っておくことで、鶏肉を切った後に包丁やまな板を洗う回数を減らせます。鶏肉を扱った後は、手や調理器具を洗ってください。

#### ⑤ 鍋に野菜を重ねる

1. 鍋にキャベツ100gを敷きます。
2. その上にもやし1/2袋を広げます。
3. 最後にしめじ1/2パックを広げます。
4. 野菜全体に塩をほんの少々振ります。

#### ⑥ 鶏肉と調味料をのせる

1. 野菜の上に鶏むね肉を重ならないように並べます。
2. 鶏肉全体に酒小さじ1を回しかけます。
3. にんにくチューブ1～2cmを、鶏肉の上に数か所に分けてのせます。

#### ⑦ 蒸し煮にする

1. 鍋にふたをして、弱めの中火にかけます。
2. 3～4分加熱し、野菜から水分が出て鍋底に少し汁が出てきたら弱火にします。
3. ふたをしたまま、さらに5～6分蒸し煮にします。

※途中で水分が出ているか確認します。水分が少なく焦げそうな場合は、水を大さじ1程度加えてください。

#### ⑧ 鶏肉の火の通りを確認する

1. 鶏肉の一番厚い部分を確認します。
2. 中心まで十分に火が通っていることを確認します。
3. 火が通っていない場合は、ふたをして1～2分ずつ追加加熱します。

※中心温度75℃で1分以上、または同等の加熱が目安です。

#### ⑨ ポン酢を加える

1. 火を止めます。
2. 蒸し煮で出た汁も一緒に、ポン酢小さじ2～2.5を加えます。
3. 鶏肉と野菜を軽く混ぜ、全体にポン酢を絡めます。

#### ⑩ 盛り付ける

1. 主菜を器に盛り付けます。
2. 鍋底に残った汁も一緒にかけます。
3. 冷奴を冷蔵庫から取り出し、しょうゆ小さじ1/2をかけます。

---

### 【ポイント】

- 水は基本的に加えず、キャベツともやしから出る水分を利用します。
- 最初から強火にすると焦げる可能性があるため、弱めの中火から弱火にします。
- にんにくは鶏肉の上にのせて蒸すことで、焦げを防ぎながら風味を出します。
- 鶏肉が厚い場合は、火が通るまで追加加熱してください。
- 蒸し煮で出た汁には野菜と鶏肉の旨味が含まれているため、捨てずに使います。
- ポン酢は最後に加えることで、酸味と香りを残します。
- にんにくはまず1cmから試し、風味が足りなければ2cmに増やします。

## 副菜：冷奴＋わかめ

### 【材料・1人分】

- 木綿豆腐：100g
- 乾燥わかめ：1g
- 長ねぎ：少量
- しょうゆ：小さじ1/2

### 【作り方】

1. 乾燥わかめ1gを水で戻し、水気を絞ります。
2. 長ねぎを少量、小口切りにします。
3. 豆腐100gを器に盛り付けます。
4. 豆腐の上にわかめと長ねぎをのせます。
5. 食べる直前にしょうゆ小さじ1/2をかけます。
