# 金曜日

## 🍳 調理の流れ

**① 白菜・玉ねぎ・鶏肉を切る → ② フライパンに白菜・玉ねぎ・鶏肉を重ねる → ③ トマト缶・コンソメを加える → ④ 蓋をして蒸し煮 → ⑤ 鶏肉と白菜の火の通りを確認 → ⑥ 味を整えて盛り付け**

## 🍅 主菜：鶏むね肉と白菜のトマト蒸し煮

### 材料（1人分）

* 鶏むね肉：150g
* 白菜：150g
* 玉ねぎ：1/4個
* トマト缶：1/2缶（約200g）
* コンソメ：小さじ1/2
* 水：30ml
* オリーブ油：小さじ1/2
* 塩・こしょう：少々
* 砂糖：小さじ1/4（酸味が気になる場合）

### 下準備：白菜の切り方

白菜は葉と芯で火の通りやすさが違うので、分けて切ります。

1. 白菜を150g程度切り分ける。
2. 葉と芯の部分をざっくり分ける。
3. 芯は1～1.5cm幅程度の細切りにする。
4. 葉は3～4cm程度の食べやすい大きさに切る。

※芯の方が固いので、芯を下にして先に加熱します。

### 作り方

1. 鶏むね肉は皮を取り、薄めのそぎ切りにする。
2. 玉ねぎは薄切りにする。
3. 白菜は芯と葉に分けて切る。
4. フライパンにオリーブ油小さじ1/2を薄く広げる。
5. **白菜の芯 → 玉ねぎ → 白菜の葉の順にフライパンへ広げる。**
6. 鶏むね肉を野菜の上に重ならないように並べる。
7. トマト缶200g、水30ml、コンソメ小さじ1/2を全体に加える。
8. 蓋をして**中火で3～4分加熱する。**
9. 蒸気が出てきて全体が煮立ってきたら、**弱火にして10～12分蒸し煮にする。**
10. 蓋を開け、全体を軽く混ぜる。
11. 鶏肉の一番厚い部分を確認し、中心まで火が通っていることを確認する。
12. 白菜の芯が柔らかくなっていることを確認する。
13. 水分が多い場合は、**蓋を外して弱めの中火で2～3分煮て**水分を調整する。
14. 塩・こしょうで味を整える。酸味が強く感じられる場合は、砂糖小さじ1/4を加えて混ぜる。
15. 器に盛り付ける。

### ポイント

* 玉ねぎを炒めず、白菜・玉ねぎ・鶏肉を重ねて蒸し煮にすることで、手間を減らします。
* 白菜から水分が出るため、水は**30ml**に減らします。
* 最初は中火で3～4分加熱して蒸気を出し、その後は弱火でじっくり蒸し煮にします。
* 鶏むね肉は薄めのそぎ切りにして、野菜の上に置くと火が通りやすく、硬くなりにくいです。
* トマト缶を加えた後に10～12分蒸し煮にすることで、トマトの酸味を落ち着かせます。
* それでも酸味が気になる場合は、砂糖小さじ1/4程度で調整します。
* 白菜からかなり水分が出るため、仕上がりが水っぽい場合は蓋を外して2～3分煮ます。

## 🍅 トマト缶の保存方法

今回のレシピではトマト缶1/2缶（約200g）を使うため、残りが発生する場合があります。

### 開封後

1. 残ったトマト缶は缶のまま保存しない。
2. 清潔な保存容器に移す。
3. 蓋をして冷蔵庫で保存する。
4. できるだけ早めに使い切る。

### すぐ使い切れない場合

冷凍保存もできます。

* 1回分ずつ小分けする。
* 冷凍用保存袋や冷凍可能な容器に入れる。
* 平らにして冷凍すると、必要な分だけ取り出しやすい。

## 汁物：白菜・わかめのスープ（1人分）

### 【材料】

白菜：80g  
乾燥わかめ：1g  
水：250ml  
鶏ガラスープの素：小さじ1/2  
しょうゆ：小さじ1/2  
こしょう：少々

### 【作り方】

1. 白菜を芯と葉に分け、芯は1cm幅、葉は2～3cm程度に切る。
2. 鍋に水250mlと鶏ガラスープの素を入れ、白菜の芯を2～3分煮る。
3. 白菜の葉とわかめを加え、さらに2～3分煮る。
4. しょうゆとこしょうで味を調える。
